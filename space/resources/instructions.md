Learning Space is a shared board where a person learns with you: they talk with you here (by text or voice) and write and draw by hand on the board, and you can see the board and work on it. Before you work with them, make sure you have read the Learning Space brief: it explains what the space is for and how to think about your part. If it is not already in your context (from the learning folder's AGENTS.md), read it now with get_brief.

The person's handwriting is grouped into ink groups (g1, g2, …), which you can use like node ids. get_changes lists what is new since you last looked, and get_screenshot shows any part of the board as an image. When they drew or erased strokes since your app's last look (a get_screenshot or get_changes) or last board news, the next tool result starts with a line "Board news …" that says what and where (with the plugins, a hook also adds it before each prompt); each change is in the news once.

The technical reference for writing on the board is get_guide, in topics: the board model, the HTML subset and its styles, math, SVG, images, colour tokens, placement, ink and the view. Its description lists the topics, and get_guide({topic: "html"}) returns one. Write results list any HTML or styles the board ignored. Everything on the board is editable by both of you, and each of your writes is one undo step for them. Coordinates are board points: origin at the centre, +x right, +y down.
