# Mascot logo explorations v3

Generated from the supplied robot-tutor reference with the built-in image-generation tool.

## Design-system basis

- Primary ink: `#0C0E17`
- Surface white: `#FFFFFF`
- Brand violet: `#6051DC`
- Supporting neutrals: `#F8F8F8`, `#FAFAFA`, `#FCFCFC`, `#F2F2F6`
- Product principle: one violet, four greys; color is deliberately sparse.
- Shape language: soft pills/circles, rounded large surfaces, clear silhouettes, and restrained detail.

The pen colors beyond violet belong to drawing content rather than the brand/UI palette, so they were excluded from these marks.

## Directions

1. `01-helmet-app-icon.png` — compact helmet mark on an intentional ink app-icon tile.
2. `02-board-peek-emblem.png` — character-rich emblem preserving the helmet, hands, board, and pencil.
3. `03-drawing-gesture-mark.png` — expressive secondary mark built around the tutor's drawing gesture.

## Final prompt briefs

All directions asked for the supplied robot as the identity reference, a crisp flat vector-style raster master, a strong small-size silhouette, no text, and an exclusive `#0C0E17` / `#FFFFFF` / `#6051DC` palette.

- Helmet app icon: simplify the oval helmet, black face visor, white eyes, antenna, side ring, and tiny violet pencil tip into a centered app-icon mark on a solid ink rounded-square tile.
- Board-peek emblem: simplify the robot peeking over a rounded whiteboard edge, preserving both hands and a short violet pencil on a genuinely transparent background.
- Drawing-gesture mark: simplify the robot head and one arm drawing a single confident violet curved underline on a genuinely transparent background.

## Notes

These are raster concept masters, not production vectors. The selected direction should be redrawn as SVG before final favicon and app-icon export so curves, optical spacing, and exact token colors can be locked deterministically.
