## Downloaded on demand, not shipped

The local voice is optional. When the learner installs it from Settings, the
app downloads these parts from sherpa-onnx's GitHub releases into
`~/.askaboard/models/`. It runs them as a separate program and never links
them into the app (decision D9).

| Part | License |
| --- | --- |
| sherpa-onnx command-line program | Apache-2.0 |
| Kokoro text-to-speech model | Apache-2.0 |
| espeak-ng (data and code inside the sherpa-onnx build) | GPL-3.0 |
